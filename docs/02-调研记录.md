## 四、方法说明（下次换人也能照着做）

1. **七段提问顺序**：还原最近一单 → 定分工 → 量时间 → 找异常 → 要证据 → 探边界 → 收口问"还该找谁"。一次只问一个。
2. **不接受的回答**：「经常」「有时候」「一般」。听到就追一句"最近一次是什么时候、那次具体发生了什么"。
3. **不接受的口径**：只给结论不给来源的数字。追"这个数是从系统导的，还是您记的"。
4. **五类废问题**（本次已规避）：反问式（"您觉得 AI 能帮您做什么"）、平均值式（"平均一天多少单"）、假设式（"如果有个功能您会用吗"）、越界式（"其他科室也这样吧"）、替人确认（"领导应该支持吧"）。
5. **收口统一问**："还有谁我应该去问？我问漏了什么？" —— 本次 4 个待补证项里有 3 个是这句问出来的。
