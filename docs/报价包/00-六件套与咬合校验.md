## 二、六条校验点的复算过程

### ① 成本拆解（01）能不能由 02/03/04 推出来

```text
人力   232,750  ← 02 表 合计行（95 人天 × 2,450）
模型         0  ← 03 表 档0 基准档年成本
服务器  40,000  ← 04 表 推荐方案 A 一次性投入
数据    29,400  ← 01 表 数据行（12 人天 × 2,450）
运维    58,800  ← 01 表 运维行（24 人天 × 2,450）
--------------------------------------------
合计   360,950  = 01 表 合计行 ✅
```

这条最容易假咬合：**模型和算力两处同时计入**。若把 40,000 的 GPU 既当"服务器"又按月摊进"模型"，合计会变成 373,333，多收 1.2 万，且对不上任何一张表。我的处理是：模型费只记 token，硬件只记服务器，**永不双算**。

### ② 人力是不是一个数

```text
FDE 30 + 后端 35 + 前端 18 + 测试 12 = 95 人天
95 × 2,450 = 232,750          ← 02 表
232,750                        ← 01 表 人力行
232,750                        ← 06 报价单 1.1 项
                               ✅ 三处一致
```

按阶段拆的横竖要对得上（02 表列方向）：

```text
S1-S2 8 + S3 6 + S4 8 + S5 42 + S6 14 + S7 9 + S8 5 + S9 3 = 95
```

### ③ 模型费为什么是 0，以及 0 是不是编的

```text
基准档（采用）= 私有化本地推理，token 不单独计费
月成本 0 × 12 = 年成本 0 = 06 报价单模型费 0   ✅

但 0 不等于没花钱：
  40,000 硬件 → 记在 01 服务器行（一次性）
  不摊进年服务费，否则 40,000 收两次
```

这条是整张表最容易被质疑的地方。`03` 表里我另给了三档云端对照（月 14.28 / 1,305.60 / 2,611.20），只为回答客户一句"为什么不用 API"——**它们不参与任何报价计算**。

### ④ 部署方案的推荐值就是服务器那格

```text
04 配置单：整机 36,000 + 备份盘 2,000 + 三年维保 2,000 = 40,000
01 服务器行：36,000 + 2,000 + 2,000 = 40,000              ✅
```

配置单里 10 个部件逐一加总必须是 36,000（GPU 18,000 / CPU 3,900 / 主板 2,300 / 内存 3,800 / 系统盘 1,200 / 数据盘 2,400 / 电源 1,000 / 机箱 900 / UPS 1,500 / 装配 1,000）。任意一项报价浮动，01 和 06 都要同步改。

### ⑤ ROI 的投入必须和报价单同源

```text
05 ROI 首年投入 360,950 = 06 首年合计 ✅
回本口径：累计净现金流首次为正（不是"收益累计 = 投入"）
  保守档 Y1 -239,750 → Y5 +9,850，回正 4.8 年
  中性档 Y1 -119,750 → Y2 +62,650，回正 1.66 年
```

口径不统一是 ROI 最常见的坑：用"收益累计等于投入"算会得出 2.98 年，用"净现金流"算是 4.8 年。**差 1.8 年，够客户翻脸。** 本包统一用净现金流，并在 05 里写明。

### ⑥ 两年合计怎么来的

```text
实施费        302,150  = 人力 232,750 + 数据 29,400 + 服务器 40,000
年服务费       58,800  = 运维 58,800 + 模型 0
首年          360,950  = 302,150 + 58,800          ← 与 01 合计相等
第二年         58,800
两年合计      419,750  = 302,150 + 58,800 × 2      ✅
三年合计      478,550  = 302,150 + 58,800 × 3
```

顺带校验付款节点：30% + 30% + 30% + 10% = 90,645 × 3 + 30,215 = **302,150** ✅

## 三、三处最容易不咬合的地方（我踩过的）

| 位置 | 错法 | 后果 | 正确做法 |
|---|---|---|---|
| 模型 vs 服务器 | GPU 既算硬件又按月摊折旧 | 合计多 1.2 万，且任何一张表都对不上 | 硬件只进一次性，token 只进年费 |
| 单价 vs 成本 | 成本表用 2,450、毛利用 2,450 算 | 毛利率显示 100% | 报价 2,450 / 成本 1,960，两列并存 |
| ROI 回本口径 | 用"收益累计 = 投入" | 报 2.98 年，实际 4.8 年，差 1.8 年 | 统一用累计净现金流，写进口径说明 |

## 五、这六件套的边界

1. **不咬合的是"频次类"数字**：25 例/日、11.5 例/日至今仍是口述（Q-02 未关）。它们喂给 ROI，一改就牵动 05 全表，但不影响 01–04、06（报价不随频次变）。**这是设计上的隔离**：报价锚在人天，ROI 锚在频次。
2. **02 表里的 2,450 与"练2 测算器"同源**，但原导出文件有千分位裂列问题（`¥34,100` 被解析成两列），本包金额一律纯数字。
3. **全部为合成案例**，不具备法律效力；`06` 末尾已声明。
