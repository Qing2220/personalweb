### 5. 技术栈与三条硬边界

`Python 3.11 · FastAPI · Ollama 本地部署 · 自建 harness`，不替换框架，不引入未要求的中间件：知识库用 SQLite 存索引，评测用 YAML 用例，日志用标准库。

1. 模型不在判定链上：号源结论由确定性规则算，模型只负责翻译与补全；
2. 关卡不由模型签核：模型只打分，具名确认人签结论；
3. 数据双层脱敏：入模型前一次、出站再一次。
